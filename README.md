# One Line, One Laugh

A single original joke line for the make.fun "One Line, One Laugh" bounty. The entry is one short, self-contained line built around a role reversal: the thing bought to help ends up treating its owner as the problem. It is written in plain, everyday words so the laugh lands on a single read, with no setup paragraph, no explanation, and no borrowed meme doing the work.

## Run it

```sh
node main.ts
```

This writes the joke line to `/output/entry.txt`.
